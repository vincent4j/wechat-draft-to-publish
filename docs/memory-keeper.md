## 2026-08-05 - 按需发布流程 `feature`
- **模块：** 公众号发布工作流入口与执行范围
- **触发词：** 直接完成、边做边看、只做封面、只排版、执行范围、完整回执
- **任务：** 根据用户想要的产物确定执行清单，减少步骤选择和无意义确认，并在结束时完整说明执行结果。
- **关键经验：** 用户应表达目标产物而不是理解内部步骤；真实结果确认比生成前方案确认更省交互且更有价值。
- **合同候选：** 不得自动扩大用户指定范围；局部任务默认不清理；任何范围结束后都必须报告实际完成、明确跳过、文件、校验和清理结果。
