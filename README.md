# wechat-draft-to-publish

把一份 Markdown 草稿依次完成去除 AI 味、正文配图、封面制作、公众号排版、120 字以内的公众号摘要和 100 个汉字以内的朋友圈转发文案，生成可直接发布与转发的微信公众号图文成稿。

## 工作流程

1. 去除 AI 味
2. 正文配图
3. 封面制作
4. 文章排版
5. 公众号摘要
6. 朋友圈转发文案

支持按结果选择执行范围：只做一项、执行一段流程、选择多个产物，或者生成完整发布包。
用户可以直接用自然语言说明，例如“只做封面”“从配图做到排版”“正文别动，只做配图、
封面和排版”。不需要先理解步骤编号。

- **直接完成**：按用户指定范围连续执行；先展示执行摘要，每一步仍反馈进度，但不再等待第二次“开始”确认。
- **边做边看**：只在正文、配图、封面和排版这些关键结果完成后暂停；摘要、朋友圈文案和机械校验连续完成。

原来的 `自动 N`、`分步 N` 和单独数字仍然可用。工作流不会自动扩大用户指定的范围。
第 4 至第 6 步都在本次范围内并通过校验时，会清理已知的无用候选图、参考图副本、提示词
和临时文件，同时保留正式产物。只做单项或局部范围时默认不清理，避免影响范围外文件。

## 使用方式

将 Skill 安装到项目的 `.agents/skills/`：

```bash
git clone https://github.com/vincent4j/wechat-draft-to-publish.git \
  .agents/skills/wechat-draft-to-publish
```

然后在 Codex 中使用：

```text
$wechat-draft-to-publish 处理这篇文章
```

Skill 会先识别文章草稿和你真正需要的产物。要求已经明确时直接执行；只有“处理一下这篇
公众号文章”这类范围和方式都不清楚的请求，才让你选择“直接完成”或“边做边看”。

例如：

```text
$wechat-draft-to-publish 直接完成这篇文章的完整发布包
$wechat-draft-to-publish 只帮我排版这篇文章
$wechat-draft-to-publish 正文不要改，从配图做到排版，边做边看
```

## 默认效果

- 正文配图：`saas-guide`、`per-section`、`macaron`
- 图片目录：文章同目录下的 `assets/`
- 公众号封面：2.35:1、系列定制配色、手绘隐喻风格
- 公众号排版：摸鱼绿、16px 正文、8px 两侧留白，不添加正文封面卡、目录或互动尾卡
- 最终生成纯净 HTML 和一键复制预览版
- 公众号摘要：单段、无标题和链接，不超过 120 字，并单独保存为 Markdown
- 朋友圈转发文案：自然分享口吻、直接进入问题或观点、单段、无链接和话题标签，不超过 100 个汉字，并单独保存为 Markdown
- 收尾清理：删除无用候选图、未引用配图、参考图副本、提示词和已知临时文件
- 发布包一致性：检查封面、配图、摘要和朋友圈文案是否围绕同一篇最终正文
- 完整执行回执：结束时明确列出实际完成、明确跳过、生成文件、检查结果和清理结果
